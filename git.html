Tableau des commandes Git

Commande Description
git init Initialiser un nouveau dépôt git
git clone <url> Cloner un dépôt distant
git status Afficher l’état du dépôt
git add <fichier> Ajouter un fichier à l’index
git commit -m "message" Valider les modifications avec un message
git push Envoyer les commits sur le dépôt distant
git pull Récupérer les modifications du dépôt distant
git log Afficher l’historique des commits
git branch Lister les branches
git checkout <branche> Changer de branche
git merge <branche> Fusionner une branche
git remote -v Afficher les dépôts distants
git diff Afficher les différences entre les fichiers
